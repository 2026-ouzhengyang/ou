# 桌面增强版（Electron）

网页版（根目录的 `index.html`）已经能用。这个目录是**可选**的增强版，多出来两件事：

1. **直读磁盘**——知识库的正文和向量索引存成真实文件，几十 MB 也不怕；网页版只能受限在浏览器的存储配额里。
2. **连本地模型**——「六艺」那一页要调用 `127.0.0.1:11434`。网页版在 `file://` 下会被浏览器的跨源策略挡住，桌面版没有这个限制。

## 目录

```
desktop/
├── main.js           主进程：窗口、数据目录、自检/导入/体检等模式
├── preload.js        桥接层：只把必要的本地能力交给页面
├── renderer/
│   └── index.html    就是根目录那份 index.html，原样复制
├── smoke.js          应用内冒烟测试（60 项）
├── import-kb.js      批量导入脚本（往知识库里灌目录用）
├── icon.png / icon.ico
└── package.json
```

## 怎么构建

不需要打包器，就是把源码放进官方 Electron 发行包的 `resources/app` 里：

```bash
# 1. 拿一份 Electron 预编译包（Windows x64）
#    https://github.com/electron/electron/releases
#    本项目是在 31.7.7 上做的，换更新的版本一般也没问题
curl -LO https://github.com/electron/electron/releases/download/v31.7.7/electron-v31.7.7-win32-x64.zip
unzip electron-v31.7.7-win32-x64.zip -d 政点

# 2. 把源码放进去
mkdir -p 政点/resources/app/renderer
cp main.js preload.js smoke.js import-kb.js package.json 政点/resources/app/
cp renderer/index.html 政点/resources/app/renderer/

# 3. 改名就可以跑了
mv ORIGIN/electron.exe 政点/政点.exe
```

想给它换个图标和版本信息，用 [rcedit](https://github.com/electron/rcedit)：

```bash
rcedit 政点/政点.exe --set-icon icon.ico \
  --set-version-string ProductName "政点" \
  --set-version-string FileDescription "个人 AI 成长控制台" \
  --set-file-version 2.0.0
```

> 注意：rcedit 不能原地改写已经在用的 exe。先把图标打到一份干净的 electron.exe 上，再改名/移动。

纯离线精简版：把 renderer/index.html 换成带 window.ZD_PURE = true 注入的版本，
并在 resources/app 里放一个空的 pure.flag 文件 —— 主进程会收起菜单里的六艺和模型，
窗口标题变成「政点 纯离线版」。其余构建步骤完全一样。

## 数据存在哪

默认是安装目录下的 `政点-数据/`（便携模式）：

```
政点-数据/
├── 运行数据/        浏览器存储（localStorage / IndexedDB）
├── 知识库/
│   ├── 原文/        你上传的每一份资料的正文副本
│   └── 索引/        切好的段落与向量
├── 自动备份/        每次改动写一份版本化快照，启动时认最新的那份
└── 导入日志.txt
```

想换地方，设环境变量 `ORIGIN_DATA_DIR` 指过去。

> 这里的备份是"版本化快照"而不是"覆盖同一个文件"。
> 原因很实在：有些盘（只读挂载、同步盘、权限受限的目录）不允许覆盖已有文件，
> 覆盖式备份会**静默失败**——写进去当场读得到，重启全没。每次写新文件就没这个问题。

## 自检模式

`main.js` 里带了几条命令行入口，改完代码想确认没改坏时很好用：

| 环境变量 | 作用 |
|---|---|
| `ORIGIN_SMOKE=1` | 跑应用内冒烟测试（60 项），结果打到 stdout 的 `__SMOKE_BEGIN__` / `__SMOKE_END__` 之间 |
| `ORIGIN_SHOTS=1` | 顺带让窗口给自己拍照（配合 `ORIGIN_SMOKE=1` 用）；`ORIGIN_SHOT_SIZE=390x844` 可以按手机视口拍 |
| `ORIGIN_KBSTAT=1` | 体检：打印数据目录、库内资料数、磁盘文件数，写到 `ORIGIN_KBSTAT_OUT` |
| `ORIGIN_KBSTAT_SHOT=1` | 在上面基础上顺手拍一张知识库页的截图（只切路由，不动数据） |
| `ORIGIN_KBRESTORE=1` | 用磁盘上的索引文件**重建**库内清单，不重算向量 |
| `ORIGIN_IMPORT=1` | 按 `ORIGIN_IMPORT_MANIFEST` 指定的清单批量导入资料 |
| `ORIGIN_IMPORT_RESET=1` | 批量导入前先清空 |
| `ORIGIN_TRACE=路径` | 把内部动作记一份日志，排查"数据到底存哪去了"时用 |
| `ORIGIN_NOGPU=1` | 强制软件渲染，虚拟机/远程桌面上用 |

例：

```bash
ORIGIN_SMOKE=1 ORIGIN_NOGPU=1 ./政点.exe
```

## 没有显卡的机器

「设置」里不写死任何速度数字。点一下「让它自己报数」，它会拿这台机器上真实可用的模型跑一次，直接报出实测字/秒。没显卡、纯 CPU 也能跑，只是慢一些——这台开发机实测 `qwen2.5:3b` 约 12 字/秒，`qwen2.5:1.5b` 约 22 字/秒。
